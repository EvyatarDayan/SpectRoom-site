# SpectRoom

Marketing site for SpectRoom - a dating and social discovery app built around verified profiles and privacy-first security.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting started

Requires Node.js 20+.

```bash
nvm use
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` - local development
- `npm run build` - production build
- `npm start` - serve production build
